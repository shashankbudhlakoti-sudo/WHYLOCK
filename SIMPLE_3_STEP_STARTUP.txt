================================================================================
                   SIMPLE 3-STEP STARTUP GUIDE
================================================================================

PROBLEM: Application not starting on port 8085

SOLUTION: Follow these 3 steps carefully


STEP 1: START POSTGRESQL
════════════════════════════════════════════════════════════════════════════════

1. Open Command Prompt or PowerShell as Administrator
2. Type this exactly:
   
   "C:\Program Files\PostgreSQL\15\bin\pg_ctl.exe" -D "C:\Program Files\PostgreSQL\15\data" start

3. You should see:
   "waiting for server to start.... done"
   "server started"

4. Keep the window open


STEP 2: START REDIS
════════════════════════════════════════════════════════════════════════════════

1. Open NEW Command Prompt or PowerShell as Administrator
2. Type this exactly:

   "C:\Program Files\Redis\redis-server.exe"

3. You should see:
   "Ready to accept connections"

4. Keep the window open


STEP 3: START WHYLOCK APP
════════════════════════════════════════════════════════════════════════════════

1. Open NEW Command Prompt or PowerShell
2. Navigate to:
   
   cd C:\Users\shash\OneDrive\Desktop\whylock

3. Type exactly:

   java -jar target\whylock-0.0.1-SNAPSHOT.jar

4. Wait for message:
   "Started WhylockApplication in X.XXX seconds"

5. Open browser: http://localhost:8085


IMPORTANT NOTES
════════════════════════════════════════════════════════════════════════════════

✓ Keep ALL 3 command windows OPEN
✓ Do NOT close any windows
✓ Wait 30-40 seconds total for startup
✓ If you see red [ERROR] messages, note them down
✓ Application runs on port 8085

WHAT IF PORT IS DIFFERENT?
════════════════════════════════════════════════════════════════════════════════

If you see: "port already in use"

The port 8085 might be taken by another process.
Kill it or wait a minute and try again.
