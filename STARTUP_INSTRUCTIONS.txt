================================================================================
                WHYLOCK STARTUP - POSTGRESQL & REDIS NOT SERVICES
================================================================================

IMPORTANT: Your PostgreSQL and Redis are installed but NOT as Windows Services.
You need to start them manually using the helper scripts provided.

================================================================================
EASIEST METHOD - ONE COMMAND START ALL
================================================================================

Step 1:
  Right-click file: start-all.bat
  Select: "Run as Administrator"
  
Step 2:
  Wait for all messages to appear
  Application will start automatically
  
Step 3:
  Open browser: http://localhost:8085
  
This is the EASIEST and RECOMMENDED method!


================================================================================
ALTERNATIVE METHOD - START SERVICES SEPARATELY
================================================================================

If you prefer to start services one by one:

STEP 1: Start PostgreSQL
──────────────────────────────────────────────────────────────────────────────
Double-click:  start-postgresql.bat
Wait for:      "PostgreSQL is running on port 5432"
Keep window:   Open (or it may stop)


STEP 2: Start Redis
──────────────────────────────────────────────────────────────────────────────
Double-click:  start-redis.bat
Wait for:      "Redis is running on port 6379"
Keep window:   Open (or it may stop)


STEP 3: Start WhyLock
──────────────────────────────────────────────────────────────────────────────
Double-click:  run.bat
Wait for:      "Started WhylockApplication"
Access:        http://localhost:8085


================================================================================
WHAT EACH SCRIPT DOES
================================================================================

start-all.bat
  ✓ Starts PostgreSQL
  ✓ Starts Redis
  ✓ Creates 'whylock' database if needed
  ✓ Builds WhyLock application
  ✓ Starts WhyLock on port 8085
  → RECOMMENDED - USE THIS ONE!

start-postgresql.bat
  ✓ Starts PostgreSQL database server
  ✓ Checks if running on port 5432
  → Use this to start only PostgreSQL

start-redis.bat
  ✓ Starts Redis cache server
  ✓ Checks if running on port 6379
  → Use this to start only Redis

run.bat
  ✓ Builds and runs WhyLock
  ✓ Requires PostgreSQL and Redis already running
  → Use after starting both services


================================================================================
IMPORTANT: KEEP WINDOWS OPEN!
================================================================================

When you run these scripts, they start server applications.

DO NOT CLOSE the command prompt windows!

If you close them, the services will stop.

Keep them running in the background while using WhyLock.

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "PostgreSQL installation not found"
Solution:
  → Install PostgreSQL from: https://www.postgresql.org/download/
  → Choose default installation path
  → Remember PostgreSQL password

Problem: "Redis installation not found"
Solution:
  → Install Redis from: https://github.com/microsoftarchive/redis/releases
  → Download: Redis on Windows (release)
  → Extract to default location

Problem: "Port 5432 already in use"
Solution:
  → PostgreSQL may already be running
  → Or another application using same port
  → Try: start-all.bat (handles this)

Problem: "Port 6379 already in use"
Solution:
  → Redis may already be running
  → Or another application using same port
  → Try: start-all.bat (handles this)

Problem: "ERR_CONNECTION_REFUSED on 8085"
Solution:
  → Make sure start-all.bat completed
  → Or all 3 services are running
  → Wait longer for startup
  → Check console for errors

Problem: "Database does not exist"
Solution:
  → Run: start-all.bat (creates it automatically)
  → Or create manually:
    1. Open pgAdmin
    2. Right-click → Create Database
    3. Name: whylock
    4. Owner: postgres

Problem: Windows says "access denied"
Solution:
  → Right-click the .bat file
  → Select: "Run as Administrator"
