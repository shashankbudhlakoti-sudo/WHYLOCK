================================================================================
                    HOW TO START WHYLOCK APPLICATION
================================================================================

STEP 1: START POSTGRESQL
────────────────────────────────────────────────────────────────────────────────
Method A (Windows Services):
  1. Press Windows Key + R
  2. Type: services.msc
  3. Find: "postgresql-x64-XX" (or similar)
  4. If stopped, Right-click → Start
  5. Wait for status to show "Running"

Method B (PostgreSQL Application):
  1. Open PgAdmin or PostgreSQL Shell
  2. Verify it's running

Method C (Command Prompt):
  1. Open Command Prompt
  2. Type: psql -U postgres
  3. If connected, PostgreSQL is running


STEP 2: START REDIS
────────────────────────────────────────────────────────────────────────────────
Method A (Windows Services):
  1. Press Windows Key + R
  2. Type: services.msc
  3. Find: "Redis" service
  4. If stopped, Right-click → Start
  5. Wait for status to show "Running"

Method B (Redis Command Prompt):
  1. Look for Redis installation folder
  2. Run: redis-server.exe
  3. Keep the window open

Method C (Windows Subsystem):
  1. If using WSL, start Redis in WSL terminal
  2. Keep terminal open

TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────────

Problem: "ERR_CONNECTION_REFUSED on port 8085"
Solution:
  1. Make sure run.bat completed successfully
  2. Check console for error messages
  3. Verify PostgreSQL is running
  4. Verify Redis is running
  5. Check firewall isn't blocking port 8085

Problem: "database 'whylock' does not exist"
Solution:
  1. Create database: See STEP 3 above
  2. Or let Spring Boot auto-create (if DDL enabled)
  3. Restart the application

Problem: "Connection refused for Redis"
Solution:
  1. Start Redis service
  2. Check port 6379 is available
  3. Restart WhyLock app

Problem: "PostgreSQL connection refused"
Solution:
  1. Start PostgreSQL service
  2. Check credentials in application.properties
  3. Verify user 'postgres' exists with correct password
  4. Restart WhyLock app
